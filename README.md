## 🧭 What This Tool Does

windows-forensic-automation automates Windows forensic examinations. It accepts common forensic image formats, reads Windows artifacts, and turns the parsed data into understandable results.

The workflow is built around the questions investigators actually ask:

- What happened on this Windows system?
- Was data copied out?
- Which USB devices were connected?
- What malware or suspicious activity is present?
- Was a phishing or ClickFix-style event involved?
- Was remote management software used?
- Is there evidence of ransomware activity?

The application processes the image, parses relevant artifacts, and presents answers tied to the selected case type. Every parsed artifact can be exported as CSV, so you can review the underlying details yourself. A court-ready report is also generated from the findings.

Validated against NIST CFReDS, the project is intended for blue-team, cybersecurity, DFIR, incident response, malware analysis, and digital forensics work.
